# TabICLv2 Regressor — DIMER Pipeline

DIMER pipeline for fine-tuning TabICLv2 on tabular regression datasets.

Deployable repositories:

- `tabicl-regressor-dataset-validator`
- `tabicl-regressor-finetuner`
